# 보안 규칙 테스트 (배포 전 필수)

바로 위 폴더의 실제 `firestore.rules` 를 에뮬레이터에 올려서,
"고객 흐름은 살아있고 / 외부인 위험행위는 막히는지" 자동으로 확인합니다.
**여기서 통과해야 배포하세요. 이 테스트는 실제 사이트/DB를 건드리지 않습니다.**

## 준비물
- Node.js 18+  (https://nodejs.org)
- Java (에뮬레이터 구동용). 없으면 "OpenJDK 17" 설치.

## 실행 (이 _security_test 폴더 안에서)
```
npm install
npm test
```

## 기대 결과
맨 아래에 `==== 결과: N 통과 / 0 실패 ====` 가 나오면 성공입니다.
- 외부인: 시세/신청 읽기는 되지만, **삭제·수정·블랙리스트 열람은 전부 차단**
- 고객: 신청 작성·본인 신청 수정·후기 작성·본인 회원탈퇴 OK, **신청 삭제는 차단(관리자만)**
- 관리자: 전체 삭제·수정·블랙리스트 OK

❌(실패)가 있으면 배포하지 말고 알려주세요. 규칙을 조정합니다.

## 통과했다면 — 실제 배포 (코드 폴더 최상위에서)
```
firebase deploy --only firestore:rules,hosting
```
- `firestore:rules` = 새 잠금 규칙 적용
- `hosting` = 실시간 시세 티커 삭제한 index.html 반영
- 배포 후 직접 점검: 홈 → 시세조회 → 신청 제출 → 배송방법 입력 / 관리자 목록·상태변경
- 문제 시 Firebase 콘솔 → Firestore → 규칙 → '버전 기록'에서 즉시 롤백

## 되돌리기(로컬)
- 규칙 원복:  `firestore.rules.bak_open`
- 홈 원복:    `index.html.bak_before_lock`
