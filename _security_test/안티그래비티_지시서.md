# 안티그래비티에 시키는 법

## 방법
1. 안티그래비티에서 이 프로젝트 폴더(used-phone-market)를 엽니다.
2. 아래 "붙여넣을 지시문"을 그대로 복사해 안티그래비티 대화창에 붙여넣습니다.
3. 안티그래비티가 테스트를 돌리고 결과를 보여줄 거예요.
   - "0 실패"가 나오면 → 저(클로드)에게 결과를 알려주세요. 배포는 그다음에.
   - 실패가 나오면 → 어떤 항목이 실패했는지 알려주세요. 규칙을 조정합니다.

---

## 붙여넣을 지시문 (이 줄부터 복사)

너는 이 저장소에서 **테스트만 실행**하면 돼. 아래 규칙을 반드시 지켜.

[배경]
- `firestore.rules` 에 새 보안 규칙(1단계 안전 부분잠금)이 적용돼 있고,
  `_security_test/rules.test.mjs` 가 이 규칙을 Firebase 에뮬레이터로 검증한다.

[할 일]
1. `_security_test` 폴더로 이동.
2. `npm install` 실행.
3. `npm test` 실행 (firebase 에뮬레이터를 띄우고 rules.test.mjs 를 돌린다).
4. 콘솔 출력 전체, 특히 마지막의 `==== 결과: N 통과 / M 실패 ====` 줄을 그대로 보고해.

[환경]
- Node.js, Java(JDK 17+)가 필요하다. 없으면 설치하거나, 설치가 막히면 그 사실을 보고해.

[절대 하지 말 것 — 매우 중요]
- `firestore.rules`, `index.html`, 그 외 어떤 앱 코드도 **수정하지 마**.
- 테스트가 실패해도 **규칙을 느슨하게 바꿔서 통과시키지 마**. 실패 항목만 보고해.
- `firebase deploy` 등 **배포는 절대 하지 마**. 실제 사이트/DB를 건드리는 명령 금지.
- `.firebaserc` 의 실제 프로젝트(rejeuphone)에 연결되는 명령 금지.
  테스트는 데모 프로젝트(demo-sharaphone)와 로컬 에뮬레이터에서만 돈다.

[보고 형식]
- 통과/실패 개수
- 실패가 있으면 실패한 항목 이름들
- 설치/실행 중 막힌 게 있으면 그 에러 메시지

## 통과한 뒤에 (배포는 사람이 직접)
테스트가 "0 실패"면, 코드 폴더 최상위에서:
```
firebase deploy --only firestore:rules,hosting
```
배포 후 홈→시세조회→신청제출→배송방법 / 관리자 목록·상태변경 점검.
문제 시 Firebase 콘솔 → Firestore → 규칙 → 버전 기록에서 롤백.
